# 🚀 12-Week GitHub Publishing Roadmap (1 Hour Daily, Mon–Fri)

## 📌 Overview
This roadmap helps you master **OOP, C#, .NET Core, and Design Patterns** step by step, while building **portfolio-ready projects** for GitHub.  
Each week is broken into **daily 1-hour tasks** so you can progress steadily.

---

## 🔹 Month 1: Foundations & Advanced C#
**Goal:** Build strong OOP + C# fundamentals.

### Week 1 (Library System – Part 1)
- Mon: Review OOP pillars (Encapsulation, Abstraction).  
- Tue: Implement Book class hierarchy.  
- Wed: Add Borrower class + relationships.  
- Thu: Implement basic CRUD (Add/Remove books).  
- Fri: Push repo with README explaining OOP usage.

### Week 2 (Library System – Part 2)
- Mon: Add search functionality (LINQ).  
- Tue: Add borrow/return workflows.  
- Wed: Apply SOLID principles.  
- Thu: Write unit tests.  
- Fri: Update README with screenshots.

### Week 3 (Task Scheduler – Part 1)
- Mon: Learn Delegates, Func, Action.  
- Tue: Implement event-based reminders.  
- Wed: Add LINQ filtering for tasks.  
- Thu: Async/Await for notifications.  
- Fri: Push repo with demo GIF.

### Week 4 (Task Scheduler – Part 2)
- Mon: Add persistence (JSON file storage).  
- Tue: Add error handling/logging.  
- Wed: Refactor with clean code principles.  
- Thu: Write README with diagrams.  
- Fri: Polish repo and push.
